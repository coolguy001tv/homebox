# 货币代码从 RMB 改用 ISO 4217 标准 CNY

Group 的货币设置原本以 `"rmb"/"RMB"` 作为人民币代码，但它不是合法的 ISO 4217 代码。前端把该代码直接传给 `Intl.NumberFormat` 时浏览器无法识别，会原样输出代码（如 `RMB 1,000.00`）而不是符号 ¥；Group Setting 里的 Example 因硬编码了合法码 `CNY` 才侥幸显示正常。合法的人民币 ISO 4217 代码是 `CNY`。

决定：领域层统一改用 `cny`/`CNY`——Ent enum、前端货币表、API 契约一并改名，新增数据迁移把存量 `rmb` 行更新为 `cny`，写库路径对旧 `RMB` 输入做过渡期归一化。

Considered Options:

- **保留 `RMB` 代码、仅显示层做映射**——被否决。货币代码是 API 契约字段，保留非标准代码会让任何假设 ISO 4217 的消费方（导出、通知、第三方集成）再次踩坑；本项目处于预发布期、几乎无存量数据，迁移成本趋近于零，趁早改正是一劳永逸。
